卷首语为什么这样读

《中庸》最容易被读成两句话：一句是「中庸就是不走极端」，一句是「诚就是真诚」。两句都太省。本书先把「中庸」还原成「度」——不是折中，是在两端之间找到此刻该站的那一点；再把「诚」还原成「自成」——不是对别人坦白，是自己对自己不欺。

全书的主线只有一条：从「天命之谓性」到「无声无臭」，人如何把自己这一份性，修成一件看得见的事。中间三十一章，都是这条线上的刻度。
